# Currency Converter

A React-based currency converter that allows users to convert between different currencies using live exchange-rate data.

## Features

- Convert currencies in real time
- Select source and target currencies
- Swap currencies instantly
- Fetch live exchange rates using an API
- Responsive user interface
- Currency-themed background
- Reusable `InputBox` component
- Custom currency conversion hook

## Technologies Used

- React
- JavaScript
- Vite
- Tailwind CSS
- Currency API

## React Concepts Practiced

- Components
- Props
- `useState`
- `useEffect`
- `useId`
- Custom Hooks
- Event Handling
- Controlled Inputs
- API Fetching
- Conditional Rendering
- Array/Object Methods

## How It Works

1. Select the currency you want to convert from.
2. Enter the amount.
3. Select the target currency.
4. Click **Convert**.
5. The application fetches the exchange rate and displays the converted amount.
6. Use the **Swap** button to switch the currencies.

## Installation

Clone the repository:

```bash
git clone <https://github.com/divyansh630/React-Practise-Projects.git>
```

Navigate to the project:

```bash
cd currency-convertor
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
