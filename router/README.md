# React Router Practice

A React project built to practice and understand routing and navigation using React Router.

## Features

- Multiple pages with React Router
- Navigation between routes
- Dynamic routes using URL parameters
- Nested routing
- Layout components
- GitHub API integration
- Responsive UI with Tailwind CSS

## Technologies Used

- React
- React Router
- Tailwind CSS
- GitHub API
- Vite

## Concepts Practiced

- `createBrowserRouter`
- `RouterProvider`
- `Outlet`
- `Link`
- `NavLink`
- `useParams`
- Nested routes
- Dynamic routing
- API fetching with `fetch()`
- React Hooks
